# Resolver Web v1.2.0

本版本改善现场滚榜的重启恢复、LED 显示适配与弱网运行，并提供由 GitHub Actions 构建的发布镜像。

- 当前直播、主持权限和已确认进度持久化；重启后从配置中心继续，同一观众链接自动恢复，恢复后暂停。
- 支持整屏、半屏、四分屏、自定义输出区域、32:9 等比例及安全边距，可用校准图检查四角、中文与长队名。
- 开场前缓存学校 Logo 和队伍照片；断线留屏、主持暂停推进，网络恢复后同步。兼容图片实际格式与响应头不一致的校徽。
- 修复共享奖项提前泄露其他获奖队伍、导入与预览异步覆盖、多人主持跳转冲突、观众切场资源泄漏等问题。
- 精简 README；更新图文使用指南和部署说明。

## 容器部署

镜像：`ghcr.io/albert-li-sz/resolver-web:v1.2.0`，支持 `linux/amd64` 与 `linux/arm64`。

下载并解压本发布的部署包，复制 `.env.example` 为 `.env`，设置 `RESOLVER_ADMIN_KEY` 后运行：

```bash
docker compose pull
docker compose up -d
```

管理页面为 `http://服务器IP:4173/`，用户名 `admin`；观众页面为 `/view`。

升级已有 Compose 部署前先备份数据卷，并在 `.env` 设置 `RESOLVER_IMAGE_TAG=v1.2.0`。保留原项目名和数据卷，执行上述命令升级。原源码构建方式可通过 `compose.build.yaml` 使用。

镜像由 GitHub Actions 构建，在两种架构上分别验证导入、主持控制、观众读取、预设保存及重启恢复；发布前验证匿名访问。镜像摘要见 `image-digests.json`，附件校验值见 `SHA256SUMS`。
