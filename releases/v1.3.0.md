# Resolver Web v1.3.0

配置界面统一为暖灰底色、顶部导航与胶囊控件；榜单默认使用 2K 像素渲染，可按现场设备选择 1080p、2K 或 4K。

- 重构赛事导入、校徽与照片、画面与奖项、滚榜预览、配置管理五个页面，精简重复说明，明确主要操作与字段含义。
- 分辨率可在「画面与奖项」及主持 / 观众页面的「画面设置」中选择，独立保存在本浏览器，支持跨标签同步。LED 比例、输出区域和安全边距继续独立生效。
- 修复本轮界面重构中的预览遮罩未隐藏问题，确保预览就绪后榜单可见且可用鼠标推进。
- 修复手机端撤销入口被隐藏的问题。载入使用页面内确认框，可取消、确认或撤销；若确认期间其他标签页切换了赛事，旧操作失效。
- 更新图文使用指南、截图与部署说明。

## 容器部署

镜像：`ghcr.io/albert-li-sz/resolver-web:v1.3.0`，支持 `linux/amd64` 与 `linux/arm64`，由 GitHub Actions 构建并执行启动、导入、主持 / 观众接口和重启恢复检查。

下载本发布的部署包，解压后复制 `.env.example` 为 `.env`，设置 `RESOLVER_ADMIN_KEY`，执行：

```bash
docker compose pull
docker compose up -d
```

管理入口为 `http://服务器IP:4173/`，用户名 `admin`；只读观众入口为 `/view`。

从 v1.2.0 升级前先备份数据卷，在 `.env` 中设置 `RESOLVER_IMAGE_TAG=v1.3.0`，保留原 Compose 项目名与数据卷后执行上述命令。旧 LED 设置自动补上默认 2K，其他校准参数保留。配置预设、素材与保存的滚榜进度继续使用。

分辨率改变实际 Canvas 像素，不改变揭晓顺序、排名或颁奖进度；极端超宽输出会将最长边限制在 8192 像素，面板显示实际渲染尺寸。

发布附件包含部署包、图文使用指南、示例榜单、镜像摘要和 SHA256 校验文件。
