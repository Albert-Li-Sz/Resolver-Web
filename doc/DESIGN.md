# UI 设计与校对

2026-10-26 · v1.1.0

## 参考来源

- [Hydro Docs](https://docs.hydro.ac/zh)：清晰标题层级、留白和内容分区。已打开原站检查布局。
- [Pintia UEP](https://uep.pintia.cn/dashboard)：浅灰底、白色内容区、蓝色主要操作。已在浏览器打开实际报名管理页面。
- [NXOPA-RegSYS](https://github.com/Albert-Li-Sz/NXOPA-RegSYS)：中文表单和导航风格；核对其前端样式，使用相同方向的 `#1765c1` 主色。

未复用这些项目的品牌标志、页面源码或账户数据。

## 设计稿

[数据源完整设计稿](design/data-source.png) · [显示参数设计稿](design/display-options.png)。设计稿用于界面规范，使用指南中的图片全部为真实应用截图。

五个配置页面共用白色侧栏、顶部操作区和三步流程导航，保留原有页面分工。没有加入与赛事配置无关的图表、统计或营销内容。首次进入显示空赛事和普通上传入口，示例下载跳转到 GitHub。

## 规范与对照

| 检查点 | 设计与实现 |
| --- | --- |
| 布局 | 桌面侧栏 240px、顶部 66px；内容区 36px 留白，数据导入与指引分栏，当前赛事独立分区 |
| 色彩 | 主色 `#1765c1`、背景 `#f5f7fa`、内容白底、边框 `#e4e8ef`、正文 `#182337` |
| 文字 | 中文系统字体与现有 DM Sans，标题 30px，主要导航 15px，表单标签 13px；保留帮助文字和准确的容量说明 |
| 控件 | 主要操作蓝底、次要操作白底细边、圆角 5-6px；上传和远程地址使用下划线标签页 |
| 图标 | 沿用项目原有线框 SVG 语汇，统一导航尺寸；Logo 使用代码绘制的排名柱形标志 |
| 表单密度 | 将过宽的分组留白缩小，显示布局、开关、封榜与奖项按实际顺序排列 |
| 内容与首屏 | 数据源、导入赛事、开始之前、当前赛事、下载示例榜单等核心文案与设计一致；说明文字以实际行为为准 |
| 预览边界 | 只调整 iframe 周围的配置界面；iframe 内 Canvas、播放页与只读观众页保持原文件 |

与图像稿的有意差异：帮助文案采用项目真实规则；字段选项仍为 9/12/15 行和 0-8 行偏移；素材、预设继续使用实际数据，不用图像稿中的静态内容。开场屏和奖项开关截图反映测试时的配置状态。

已在设计稿原生 1536×1024 尺寸和桌面 Browser 视图进行检查，对照了布局、文案、色彩、文字、图标、分区与控件。截图以完整页面或明确的页面区域保存，修复了最初截图右边缘被浏览器面板裁切的问题。表单的多余纵向间距已收紧。

响应式 CSS 提供横向导航、单列内容与窄屏表单。当前 Browser 的手机尺寸切换未成功；进一步使用高级调试通道时被权限检查拒绝，因此不将手机端标记为已验收。详见 [测试记录](TESTING.md)。
