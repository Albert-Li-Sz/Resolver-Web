# 配置界面设计

2026-10-29

参考：[Mastercard 设计系统](https://getdesign.md/mastercard/design-md)。五个配置页共用同一套导航、控件和文案规则；保留原有导入、素材、奖项、预览、配置管理流程。

## 样式与组件

| 项目 | 规范 |
| --- | --- |
| 色彩 | 暖灰背景 `#F3F0EE`、内容底 `#FCFBFA`、文字与主要按钮 `#141413`；橙色 `#CF4500` 仅点缀当前导航 |
| 布局 | 顶部白色胶囊导航；导入与当前赛事分栏；窄屏改为横向导航和单列内容 |
| 文字 | 中文系统字体与本地 DM Sans；页面标题 44px、分区标题 23px、表单与按钮 14px |
| 控件 | 48px 胶囊输入框；浏览器支持时直接美化原生下拉菜单，否则保留原生选择能力 |
| 按钮 | 黑色主要操作、描边次要操作、明确文字的载入与删除按钮；保留禁用与键盘焦点状态 |
| 奖项 | 仅展开当前启用的名额、名称和题目选项；保留并列、打星和待定判题规则 |
| 文案 | 删除重复页面介绍和三步流程说明；统一“赛事导入、校徽与照片、画面与奖项、滚榜预览、配置管理” |

图像概念稿用于确认整体视觉，真实页面保留项目柱形标志、准确字段及动态赛事内容。字号与纵向间距按常见笔记本工作区收紧；不把概念稿中的示意数据写入应用。

## 榜单分辨率

榜单仍按逻辑坐标排版，Canvas 独立以所选像素尺寸绘制。默认 2K（2560×1440），可选 1080p（1920×1080）与 4K（3840×2160）。预览、主持端和观众端均生效。

分辨率保存在本浏览器，与赛事预设、奖项和主持进度分开。LED 比例与输出区域继续独立生效：例如 32:9 的 2K 输出为 5120×1440。极端宽屏的最长边限制为 8192 像素，避免过大画布分配；设置面板显示实际渲染尺寸。

## 本轮校对

使用 Browser / IAB 检查了桌面导入页、下拉弹层、奖项展开、配置保存对话框、预览和主持 / 观众画面。375px 手机布局检查了导入、设置、素材和配置管理，页面无横向溢出。

逐项对照概念稿的背景、导航、文字层级、胶囊控件、内容分栏、留白和按钮。修正了下拉箭头错位、手机校徽搜索框过窄、素材页重复拼接的文案，以及没有说明含义的配置操作图标。首屏保留实际必要的容量、格式与空状态文字；没有增加营销说明。

自动验证覆盖像素尺寸、旧设置迁移、存储异常、宽屏上限、跨标签同步，以及切换分辨率时保持榜单和颁奖进度。

发布前已补齐配置载入、取消和手机撤销验收，并修复预览就绪后遮罩仍覆盖画布的问题。确认框期间若其他标签页切换了赛事，旧确认会失效。
